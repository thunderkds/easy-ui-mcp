## Approach

**Pattern reference**: the design system's `components/bundle.css` — copy the `gm-page`, `gm-eyebrow`, `gm-link`, `gm-strip*`, `gm-table*`, `gm-nodata`, `gm-warn-text` rules **verbatim** (they already reference `var(--…)`), and inline only the tokens they use into `:root`. In this repo, keep `renderIndex`'s structure and `escapeHtml` use.

**Vital slice**: inline token block + copied component rules + new header/strip markup.
**Cut list**:
- Sidebar, family nav, header bar (a single generated page has nothing to navigate to)
- Light theme (Graphite Mint has dark only)
- Bundling Plex font files (self-contained size; system fallbacks are acceptable — say so in the review)
- Restyling the per-session report

## Edge Case Checklist

- [ ] Zero sessions → strip shows "no data" in `gm-nodata`, table shows one muted "no sessions yet" row
- [ ] Very long target text wraps inside its cell (`overflow-wrap:anywhere`), never widens the page
- [ ] `failed` must not rely on colour alone — it is the word "failed" (warn is close to neon in lightness)
- [ ] All session-derived text still escaped
